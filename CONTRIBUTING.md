# Contributing

Thank you for contributing to Link2Obsidian.

## Development

Requirements:

- Node.js 22 or newer
- npm
- Docker for container verification

Run the project:

```bash
npm install
npm run dev
```

Before opening a pull request:

```bash
npm run typecheck
npm test
npm run build
```

Contributions should stay focused on converting web links into Markdown files
and attachments for an Obsidian Vault.
